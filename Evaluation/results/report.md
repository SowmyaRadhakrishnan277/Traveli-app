## Confirmatory hypotheses (alpha = 0.025 each, Bonferroni over 2)

Confirmatory tests use every destination with valid data for the two prompts being compared, so n can be larger than in the three-way analysis above. Differences here are written compact - baseline.

**H1 (primary).** The compact prompt shortens the mean distance between stops compared with baseline (n = 19).

- compact - baseline = 1.090 km, 95% CI [-0.356, 2.537]; t(18) = 1.58, p = .131, d_z = 0.36 (small); Wilcoxon p = .251
- **NOT SUPPORTED: no reliable difference at this sample size.**
- Sensitivity: to detect the observed |d_z| = 0.36 with 80% power would need about 61 destinations (alpha .05) or about 74 (alpha .025); this study had 19.

**H2 (guardrail).** The compact prompt does not reduce the verified-place rate by more than 0.05 (n = 19).

- compact - baseline = 0.006, 95% CI [-0.069, 0.080]; t(18) = 0.16, p = .871, d_z = 0.04 (negligible)
- **NON-INFERIORITY NOT SHOWN: the lower CI bound (-0.069) is not above the -0.05 margin.**

## Threats to validity

- **External validity:** destinations are a convenience sample of 20 cities; one device, one OS and one on-device model version. Results describe this model, not language models in general.
- **Ceiling effects:** a pilot suggested verified rate might sit at 100%. The full run did not show one (baseline mean 0.86), so there was room for prompts to differ.
- **Power:** with this many destinations only fairly large effects are detectable; a non-significant result is not evidence of no effect (see the sensitivity line under H1).
- **Run-to-run noise:** each cell is a single generation by a probabilistic model; a repeat run would give somewhat different numbers.
- **Distance is a proxy:** straight-line distance between stops is not travel time and says nothing about whether the plan is pleasant or safe.
- **Map coverage:** a place that exists but is missing from Apple Maps counts as 'not found', which may penalise less-mapped regions.
